# MF-Guide: RAG-Powered Mutual Fund Chatbot

A **Retrieval-Augmented Generation (RAG) chatbot** that answers questions about HDFC mutual fund schemes. Built as a class demonstration of the full RAG pipeline: ingestion → chunking → embedding → vector store → retrieval → generation.

---

## Architecture

See [architecture.md](./architecture.md) for the full system design and [PRD.md](./PRD.md) for product requirements.

```
User Query → Embed → FAISS Search → Top-K Chunks → Prompt + Context → LLM → Grounded Response
```

---

## Prerequisites

- **Python 3.10+** — [Download](https://www.python.org/downloads/)
- **OpenAI API key** — [Get one](https://platform.openai.com/api-keys)

---

## Setup

```bash
# 1. Create virtual environment
python -m venv .venv

# 2. Activate it
# Windows:
.venv\Scripts\activate
# Mac/Linux:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt
```

## Configuration

```bash
# Copy the example env file
cp .env.example .env

# Edit .env and add your OpenAI API key
OPENAI_API_KEY=sk-your-key-here
```

---

## Running the Chatbot

```bash
# First time only: build the vector store (scrapes + embeds all 5 pages)
python ingest.py --force

# Launch the chatbot
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

---

## Running Tests

```bash
# Verify vector store works
python test_vectorstore.py

# Run full test suite (12 questions)
python run_tests.py
```

## Limitations

- **Static data snapshot** — NAV and other metrics are from the scrape date, not real-time
- **Single AMC** — only HDFC schemes (no multi-AMC comparison)
- **Requires OpenAI API key** — LLM generation costs ~$0.01/query
- **Local deployment only** — no cloud hosting or multi-user support
- **Single source per scheme** — only Groww pages, no cross-referencing
